# С какого выпуска «Натальной карты» начать

Если хотите понять механику шоу, начните с Бурунова. Для выпуска, в котором гость постоянно спорит с трактовками, подойдёт Собчак. Для разговора о музыке, работе и отношениях — MONA. Это редакционный выбор по сценарию просмотра.

| Маршрут | Сначала | Затем |
|---|---|---|
| Понять формат | [Бурунов №22](https://nk-vkvideo.ru/episodes/sergey-burunov), 2 ч 03 мин. Запрос к картам на 13:21, финальный расклад около 1:58:30. | [Бузова №54](https://nk-vkvideo.ru/episodes/olga-buzova), 3 ч 14 мин. Запрос на 18:32, возвращение к нему около 3:09. |
| Посмотреть реакцию гостя | [Каграманов №19](https://nk-vkvideo.ru/episodes/roman-kagramanov), 1 ч 50 мин. Смотрите, как разговор о знаке переходит в историю о дружбе. | [Собчак №51](https://nk-vkvideo.ru/episodes/ksenia-sobchak), 2 ч 37 мин. В блоке совместимости вердикт на 2:26:43. |
| Выбрать фрагмент о карьере | [MONA №68](https://nk-vkvideo.ru/episodes/mona), 2 ч 21 мин. Карьера и деньги с 1:25:40. | [Лазарев №57](https://nk-vkvideo.ru/episodes/sergey-lazarev), 3 ч 15 мин. Тема дисциплины и отношения к успеху. |

Таймкоды относятся к версиям видео из карточек. За другими маршрутами и подборками по просмотрам можно перейти к [лучшим выпускам фан-архива](https://nk-vkvideo.ru/episodes/best?utm_source=github&utm_medium=referral&utm_campaign=natalcard_readme_pilot&utm_content=luchshie-vypuski-natalnoy-karty).
